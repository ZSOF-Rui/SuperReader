能做什么

一张卡，读出三类信息

先把边界说清楚：卡阅读的是芯片里对读卡器公开的数据，不是银行后台，也不是完整账户。不同卡片开放的文件不同，能读到的内容也会不同。

  1. 01

    交通卡

    交通联合与城市一卡通：发卡城市、应用有效期、电子钱包余额，以及卡内公开的最近交易。未收录的站点显示卡内原始编码。

    JT/T 978GB/T 31778-2015本地站点数据

  2. 02

    银行卡

    银联 PBOC 与 EMV 银行卡：卡号默认脱敏、有效期、应用标签、国家与货币、AIP/AFL 等公开数据；卡片支持时读取电子现金余额与日志。发卡行与卡种由内置 BIN 库离线推断，仅供参考。

    JR/T 0025EMVBIN 离线匹配

  3. 03

    电子证件

    支持 ICAO 9303 电子护照与港澳台通行证。通过 BAC 认证后读取证件资料；证件芯片提供时显示 DG2 照片，并可在本机保存。

    ICAO 9303BACDG2 照片

  4. 04

    本地整理

    读卡结果可以保存到「我的卡包」并自定义名称；自动保存的历史最多保留 30 条脱敏摘要。历史与卡包都在应用私有目录，卸载即清除。

    本机存储自动保存开关最多 30 条历史

  5. 05

    诊断与排查

    遇到兼容性问题，可把单次读卡导出为诊断文本，卡号会脱敏。原始数据可能包含芯片公开信息，请勿公开分享。

    单次导出卡号脱敏系统分享

  6. 06

    外观与更新

    浅色、深色与跟随系统三种明暗模式，另有松岚、墨檀、曜石、霁青四套配色，每套都含浅色与深色。应用启动后会自动检查一次更新，设置里的「检查更新」可随时复查；两处都会同时查询官网、GitHub 与镜像站的版本清单，只读取清单，不上传卡片数据。

    四套配色启动自动检查三路更新检查

读不到什么
  • 银行账户余额、可用额度、完整账单、发卡行名称、持卡人姓名、身份证号、CVV、PIN 不在 NFC 芯片的公开数据中。
  • 芯片通常不保存“制卡时间”，只能读到应用生效日期；卡阅会如实标注“芯片未公开”。
  • 交通联合身份文件（SFI 0x16）涉及个人身份信息，卡阅不会读取。
  • 所有操作均为只读：不发起消费、圈存、写卡，也不内置专有密钥；用户导入的 MIFARE 密钥只存本机、不上传，也不写进读卡报告与诊断导出。

常见问题

你可能想问

为什么读不到银行卡余额或账单？

这些信息不在 NFC 芯片的公开数据里。芯片通常只提供卡号、有效期、应用标签与部分电子现金记录；账户余额、额度和账单属于银行后台。卡阅不访问银行后台，也不会上传卡片数据，因此不会显示这些内容。

预览版和开发版有什么区别？

正式版 1.9.0 已同步预览版的四套配色、回乡证与台胞证两项实验证件、全球公开卡种目录与六张实验卡，并把换乘 / 异地用卡等标记扩展到所有交通卡记录；本机 MIFARE 密钥库也已进入正式版。预览版 1.9.0-preview6 在此基础上继续保留开发版的手机读卡桥接与开发设置项，使用独立包名，可与正式版共存。开发版 1.9.0-dev13 与实验室版 0.1.0-lab9 继续内部验证，不公开分发。实验卡与两项实验证件都尚未真卡逐张验证。

可以给保存的卡片改名吗？

可以。读卡后在结果页点「保存」即可命名；以后在卡包里重命名，结果页标题会优先显示自定义名，原卡片名作为副标题保留。名称只保存在本机，不会上传。

安装时提示“未知来源”或签名冲突怎么办？

当前 APK 都是测试签名，未上架应用商店。若系统提示未知来源，需要在系统设置中允许本次安装；若与已安装版本签名不同，需要先卸载旧版。卸载会清除本机历史与卡包。

Windows 版现在能做什么？

Windows 1.1.0-preview2 通过 USB PC/SC 读卡器读取银行卡芯片的公开数据，需要读卡器、正常驱动和 Windows 智能卡服务。它没有代码签名，也未在真实读卡器与真实银行卡上验收；不支持八达通、Suica 或护照，手机读卡桥接只在开发版提供。

应用会自动联网检查更新吗？

启动后会自动检查一次：发现更高版本且该版本未提示过时弹窗，同一版本只提示一次；你也可以随时在设置里点“检查更新”复查。检查会同时通过 HTTPS 读取官网、GitHub 与镜像站的版本清单，只发送普通网络请求，不上传卡片数据；三处都失败时不会弹窗打扰。读卡过程不联网。

可以读别人的卡吗？

请只读取本人持有或已获得明确授权的卡片。卡阅不提供破解、绕过、复制或模拟功能；使用时请遵守当地法律法规与卡片协议。
